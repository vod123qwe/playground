# 📒 Vocab — Twoje słowa do opanowania (z powtórkami)

Ty dajesz słowo (albo bierzemy je z sesji) → robimy z nim ćwiczenia → słowo
wraca w trybie 🔁 Powtórka wg harmonogramu, aż wejdzie w nawyk.

**Jak ćwiczymy każde słowo (nie sama definicja!):**
1. Proste znaczenie + 1 naturalny przykład.
2. Kolokacje / rodzina słów (z czym chodzi w parze, formy: czasownik/rzeczownik…).
3. **Twoje** zdanie — sam go użyjesz (to się utrwala, nie definicja).
4. Powtórki w odstępach: **1 dzień → 3 dni → 7 dni → 21 dni**. 4 czyste = opanowane ✅.
